# SFI DATAHISTORY

`DATAHISTORY` is the permanent ledger for destructive persistence cleanups.

A DATAHISTORY entry records the exact source commit, snapshot timestamp, SHA-256, pre-cleanup inventory, preservation/purge boundary, GitHub Actions evidence artifact, and post-reset receipt. Database dumps are never committed in plaintext because this repository is public.

The 2026-09-12 archive was created under explicit Founder direction: preserve a recoverable pre-cleanup database snapshot, remove development-generated persistence, retain the longitudinal World / World Vector evidence plane, and allow future operational persistence to be populated by real observations, hypotheses, evidence and institutional use rather than SFI development residue.
