# SFI ELITE EXPERIENCE PROGRAM · 2026-09-26

Status: ACTIVE DEVELOPMENT
Owner: System Friction Institute
Canonical repository: Aptymok/system-friction
Principle: evolve existing surfaces; do not create a parallel public architecture.

## 0. Program rule

SFI does not gain decorative effects that are disconnected from institutional state.
Every elite visual behavior must project an existing object, relation, temporal state, epistemic class, execution state, or observed RETURN.
Missing data remains missing. Visual adjacency is never promoted to causality.

Global public vocabulary:

LABORATORY · REGISTRY · OBSERVATORY · SIGN IN

## 2. Cross-surface interaction grammar

### RECONSTRUCT
Purpose: expose how a visible object is composed from canonical identity, sources, methods, relations, epistemic state, limitations, and explicit missing fields.
Boundary: RECONSTRUCT never invents evidence, causality, authority, or RETURN.

### TIME
Purpose: navigate persisted historical state where real snapshots exist.
Boundary: a temporal position changes the read cutoff; it never rewrites historical observations.

### MACHINE
Purpose: expose the machine-readable contract of the same public object.
Boundary: machine view is a projection of the same object, not a second canon.

## 4. Performance contract

Targets:
- public content remains usable without GPU layer
- reduced-motion removes nonessential motion
- mobile gets lower-density graph/particle budgets
- LCP hero assets use responsive AVIF/WebP where appropriate
- no full-page WebGL dependency for documentary reading
- visual layer failure must not hide canonical content

## 5. Definition of ELITE for SFI

A visitor should be able to:
1. enter the institution;
2. observe a live or bounded field;
3. open a publication/object;
4. reconstruct its canonical identity and relations;
5. move through real historical states;
6. see the difference between expectation, action and RETURN;
7. switch to the machine representation of the same object.

Success is not “the site looks futuristic.”
Success is “the visible institution is a faithful projection of reconstructible state.”
