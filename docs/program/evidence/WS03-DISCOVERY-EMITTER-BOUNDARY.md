# WS-03 Discovery Emitter · External Notification Boundary

Indexing notification is an external distribution action. This slice does not infer an IndexNow credential, does not fabricate an external receipt and does not bind publication success to IndexNow availability.

The emitter exposes IndexNow as `NOT_CONFIGURED` with `automaticNotification=false`. A later configured adapter may perform the notification under the governed execution boundary and persist an observed external receipt in the existing WS-03 representation owner. Until then, public page/feed/sitemap/AI/MCP projections remain valid representations of already-public canonical objects, while `PUBLISHED` external propagation remains unclaimed.
