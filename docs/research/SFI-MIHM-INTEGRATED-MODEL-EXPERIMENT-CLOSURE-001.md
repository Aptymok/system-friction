## 1. Testable parent definition

MIHM is a bounded *meta-model* for systems with identifiable nodes, typed relations, flows, partially observable states, operational constraints, perturbations, histories and evidence cutoffs. It proposes that jointly modeling those features can improve specified reconstruction, event discrimination, recovery characterization or interventions compared with properly matched alternatives. Its central claim is **conditional and falsifiable**, not a universal conservation, optimal-equilibrium or self-healing law.

The existing descriptive frame remains:

`S_B(t) = (B,V,D,R,Q,C,X_B(t),P_B(t),H_B(≤t),E_B(≤t))`

Each study MUST specify B, observability, units and time cutoffs. A node/entity/relationship declaration is not an observation; a model estimate is not original-world evidence; homeostasis requires independently specified viability criteria.

### Three distinct layers
1. **MIHM scientific parent:** ontology, viability and interference hypotheses, method selection, admissibility and evaluation.
2. **MIHM-T scientific child:** predeclared temporal dependency mechanisms, lags, heterogeneous clocks, possible intervention effects and competing temporal models; no backwards physical causation.
3. **Bounded research outcomes:** separate evaluations for reconstruction, discrimination, forecast, intervention and external replication.

Phi_H, Phi_S, Phi_F, Phi_W and Phi_SFI remain method-scoped non-interchangeable instruments. The reduced kernel's compatibility `phi` is not canonical Phi.

## 2. Operational variables and inference limits

For each unit: system and node identifiers; typed edges and direction; flow quantities/units; observation/source quality and coverage; viability criterion with measurable threshold and loss; perturbation/intervention identity and authority; event/capture/publication/knowledge cutoffs; horizon; independent outcome; model version; uncertainty, rejection and abstention. Missing vs measured zero must remain distinguishable.

**Homeostatic recovery candidate** (not a new metric or law): after a preidentified perturbation, a system re-enters a predeclared viability region within a stated horizon without transferring unacceptable unmeasured loss outside the measured boundary. Compare outcomes with conventional reliability, control-theory and incident-response baselines. Distinguish resilience, adaptation and mere status continuity.

**Friction candidate:** obstruction or cost of a declared transition/constraint, with measurable burden/latency and a hypothesized mechanism. Do not equate a software `friction score` with verified external obstruction.

## 4. Integrated experiment design — two-stage minimum

### Stage A: foundational MIHM on real admissible systems
- Identify data owners, rights, source chronology, independent target and eligibility.
- Freeze M0 conventional alarms/graph/state-space and M1 relation-aware MIHM with identical eligible information.
- Independently adjudicate outcome: constraint violation or recovery within H, calibration, abstention, costs and uncertainty.
- Run out-of-time / grouped-by-system holdouts, edge randomization, missingness ablation, complexity/cost accounting.
- Report negative outcomes and conditions where simpler M0 wins. One synthetic smoke does not pass Stage A.

### Stage B: MIHM-T added value
- Apply the same bounded object, units, target and evidence cutoff.
- Compare M0 temporal baseline vs M1 parent MIHM vs M2 MIHM-T with explicit pre-cutoff lag mechanisms.
- Separate within-domain and cross-system holdouts; no post-outcome feature selection; independently verify RETURN.
- A temporal benefit is MIHM-T-specific and does not by itself validate every MIHM homeostasis claim.

### Decision thresholds

Do NOT freeze confirmatory evaluation until one task-specific primary endpoint, minimally important effect, uncertainty treatment, cost threshold, sample/system count, missingness policy, baseline competence and stopping rule are explicitly selected. No invented universal percentage thresholds.

## 5. Reality Passport evidence discipline

- **WORLD/CAPTURE:** source incident/document timestamps and original record references when actually held.
- **EVIDENCE:** admission status by canonical owner; a Lab research object is not evidence by inheritance.
- **HYPOTHESIS/INFERENCE:** parent MIHM claims, rival mechanisms, version and uncertainty.
- **VERIFICATION:** synthetic test receipts separately from empirical adjudication.
- **AUTHORITY:** existing Method Lab / ROOT / ACP scopes; no implicit elevation.
- **ACTION:** execution receipt only for steps actually executed; Github CI != real-world experiment.
- **RETURN:** real independent outcome only after observed contrast; pending otherwise.
- **CONTRAST/LEARNING:** compare frozen prediction and admissible evidence; any later promotion follows governance.
