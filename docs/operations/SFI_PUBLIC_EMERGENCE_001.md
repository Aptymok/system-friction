**Program:** `SFI-EMG-0001`

**State at declaration:** `BASELINE_OPEN`

## 1. Purpose

This is not a conventional social-media campaign. It is a governed public observation window in which SFI becomes its own bounded object and measures the external response produced by controlled public perturbations.

Primary question:

> Can a research institution generate measurable external emergence through governed public perturbations while preserving the distinction between publication, observation and evidence?

The program must never infer institutional authority, causal influence, validation, market fit or methodological correctness from reach, repetition or engagement alone.

```text
PUBLICATION ≠ EVIDENCE
ATTENTION ≠ VALIDATION
ENGAGEMENT ≠ CAUSALITY
MODEL OUTPUT ≠ OBSERVATION
ROOT APPROVAL ≠ TRUTH
```

## 2. SFI placement

The launch is attached to existing organs; it does not create a parallel architecture.

| Function | Existing SFI surface | Public-emergence use |
|---|---|---|
| Public experiment record | `/emergence` | Program state, protocol, baseline/return metrics, public trace |
| External world observation | `/observatory` | Independent public readings, trajectories and evidence-governed context |
| System intake / return | `/field` | External systems enter a governed observation/intervention/return cycle |
| Method | `/mihm`, `/repository` | Explain method only after an observable object/result creates demand for it |
| Long-form corpus | `/library`, Medium | Durable interpretation and methodological notes |
| Commercial conversion | `/root/commercial` | Qualified external opportunity after human review |
| Governance | `/root` | Admission, epistemic debt, proposals, audit and canonical decisions |
| Analytics | GA4 + SFI events | Non-PII acquisition and movement between SFI surfaces |

No social platform becomes a canonical source of truth. A platform publication is a public communication record that may reference evidence; it is not evidence by inheritance.

## 14. Stop conditions

Pause the public-emergence program if:

- campaign attribution is broken;
- the site or FIELD entry is materially degraded;
- publication starts inventing evidence or certainty to maintain cadence;
- private/ROOT state leaks into public assets;
- an object requiring consent is observed without the required consent;
- the team cannot preserve the declared return window;
- multiple simultaneous perturbations make causal interpretation impossible.

A pause is not campaign failure. It is governance preserving interpretability.

## 15. Definition of success for SFI-EMG-0001

Success is not a follower threshold.

`SFI-EMG-0001` is operationally successful if, by 2026-09-16, SFI can produce an auditable record containing:

1. a pre-publication baseline;
2. channel-attributed public perturbations;
3. observed external responses;
4. explicit uncertainty and alternative explanations;
5. at least one meaningful transition from passive observation into a deeper SFI surface or governed intake;
6. a return/audit that is published even if the initial expectations were wrong;
7. a decision to continue, modify or stop based on the accumulated record.

The objective is to make SFI externally observable as an operating institution while preserving the same epistemic boundaries it requires from every other object.
