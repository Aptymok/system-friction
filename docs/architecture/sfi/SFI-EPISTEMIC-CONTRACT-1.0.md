# SFI Epistemic Contract 1.0

**Contract:** `SFI-EPISTEMIC-CONTRACT-1.0`  
**Status:** FROZEN

The following classes are non-equivalent:

```text
SOURCE ≠ RECORD ≠ EVIDENCE ≠ EPISTEMIC ASSESSMENT
≠ COGNITIVE STATE ≠ COGNITIVE EXECUTION ≠ GOVERNANCE ≠ TRUTH
```

Inference, simulation and projection retain their own epistemic class. Repetition, derivation, model agreement, Cognitive Spine presence, ROOT approval or commercial delivery do not create independent evidence by inheritance.

Every strong claim must preserve lineage sufficient to descend from claim to assessment, evidence, record and source. Confidence does not replace determinability. Contradictions and invalidations remain first-class lineage.

ROOT may govern action. ROOT does not govern truth.
