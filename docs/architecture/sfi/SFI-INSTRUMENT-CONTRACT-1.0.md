# SFI Instrument Contract 1.0

**Contract:** `SFI-INSTRUMENT-CONTRACT-1.0`  
**Status:** FROZEN

Methods, AI models, LLMs, simulation, forecasting, graphs, multiagent execution, Cognitive Twins, Organizational Twins, assurance engines and human review are instruments within governed SFI operations.

```text
AI = INSTRUMENT
COGNITIVE TWIN = SPECIALIZED INSTRUMENT
MIHM = GENERAL SYSTEMIC FORMALISM
```

Instrument output is not automatically evidence, truth or governance authority. Every run preserves input/context/output refs, instrument version, execution interval, epistemic class and reproducibility identity when applicable.

A service profile is not an instrument. It selects a governed configuration of instruments for a case.
