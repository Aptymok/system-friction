# SFI Commercial Boundary Contract 1.0

**Contract:** `SFI-COMMERCIAL-BOUNDARY-CONTRACT-1.0`  
**Status:** FROZEN CANDIDATE

The commercial layer consumes governed institute capabilities through tenant-scoped cases.

```text
CLIENT → TENANT → CASE PLATFORM → LIMITED GOVERNED SFI CORE CALLS
```

Forbidden by contract:

```text
CLIENT → ROOT
CLIENT_CASE_MEMORY = SFI_INSTITUTIONAL_MEMORY
COMMERCIAL PRODUCT → INSTITUTIONAL TRUTH
AI OUTPUT = EVIDENCE BY INHERITANCE
REPORT → ACTION WITHOUT GOVERNANCE
```

Case results enter institutional state only through:

```text
CASE RESULT
→ SANITIZATION
→ EPISTEMIC ASSESSMENT
→ INSTITUTIONAL ADMISSION PROPOSAL
→ GOVERNANCE
→ CANONICAL SFI RECORD
→ future Cognitive Spine eligibility
```

This contract creates no database write path by itself.
