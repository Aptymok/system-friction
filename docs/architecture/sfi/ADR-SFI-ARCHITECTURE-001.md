# ADR-SFI-ARCHITECTURE-001 — Constitute SFI Core v1

**Status:** ACCEPTED FOR IMPLEMENTATION  
**Version:** 1.0  
**Date:** 2026-08-16

## Context

System Friction Institute (SFI) already contains operational surfaces, Method Lab, Field, WorldSpect, Atlas, Library, MIHM, evidence machinery and an integrated Cognitive Spine. Treating these as independent products would duplicate stores, authority and semantics.

## Decision

SFI is constituted as one architecture for observing, modelling, intervening and learning from complex systems. Commercial work enters through tenant-scoped cases and service profiles; it does not create a second institute.

Five constitutional contracts are frozen together:

1. `SFI-EPISTEMIC-CONTRACT-1.0`
2. `SFI-SYSTEM-CONTRACT-1.0`
3. `SFI-TEMPORAL-CONTRACT-1.0`
4. `SFI-INSTRUMENT-CONTRACT-1.0`
5. `SFI-COMMERCIAL-BOUNDARY-CONTRACT-1.0`

Subcontracts `SFI-CASE-1.0`, `SFI-REPORT-1.0`, `SFI-SERVICE-PROFILE-1.0` and `SFI-CASE-TO-INSTITUTION-GATE-1.0` operationalize the boundary.

## Cross-cutting planes

Epistemic control, governance and Cognitive Spine continuity cross multiple surfaces. They are not sequential modules. Cognitive Spine remains selectively consumed context and is never mandatory middleware or truth authority.

## Non-goals

This ADR does not create new tables, a second memory store, new CT agents, a replacement Method Lab, direct client access to ROOT, or scientific validation by declaration.

## Commercial proof surface

The initial registry must cover System Observatory, AI Implementation Diagnostic, AI Adoption & Integration, AI Governance Assurance, Service / Help Desk Observability, Contract & Warranty Assurance, Tender Assurance, Enterprise Memory, Cognitive Reconstruction and Custom Research using the same case/evidence/system/temporal/report/governance contracts.
