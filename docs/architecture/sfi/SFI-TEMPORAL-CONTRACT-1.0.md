# SFI Temporal Contract 1.0

**Contract:** `SFI-TEMPORAL-CONTRACT-1.0`  
**Status:** FROZEN

Supported temporal modes are `CROSS_SECTIONAL`, `LONGITUDINAL`, `RETROLONGITUDINAL`, `COUNTERFACTUAL` and `PROJECTIVE`.

Temporal bases remain distinct:

```text
OBSERVED_TIME
RECONSTRUCTED_TIME
SIMULATED_TIME
PROJECTED_TIME
```

Reconstruction is not observation; projection is not future evidence. Operations that depend on historical institutional state preserve a source cutoff so the knowable state at execution time can be reproduced.
