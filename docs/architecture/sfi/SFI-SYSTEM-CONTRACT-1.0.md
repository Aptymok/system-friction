# SFI System Contract 1.0

**Contract:** `SFI-SYSTEM-CONTRACT-1.0`  
**Status:** FROZEN CANDIDATE

MIHM is the general systemic formalism. A bounded system may be represented through:

```text
NODE × DIMENSION × RELATION × FLOW × CONSTRAINT
```

and observed through state, friction, perturbation, trajectory, attractor, transition and emergence objects where implemented and evidenced.

Every construct declares implementation status: `FORMALIZED`, `OPERATIONAL`, `EXPERIMENTAL`, `DECLARED` or `NOT_IMPLEMENTED`. Naming a construct does not imply executable implementation.

SFI seeks systemic viability and adaptive capacity rather than an undefined global optimum.

## Multidimensional transformation

`MIHM-DIMENSIONAL-TRANSFER-MODEL-0` is EXPERIMENTAL. It may represent source observable, target observable, magnitude, direction, lag, gain, attenuation, constraints, context, uncertainty and evidence lineage. It does not assume that one conserved quantity moves unchanged between dimensions.
