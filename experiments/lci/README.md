## What this experiment asks

Does the *particular developmental biography of an artificial-agent subject* contribute predictive/explanatory value beyond the base model, founder seed, architecture, current context and generic/retrieval memory?

Subjects include `CT-A01` (live developmental history), `CT-B01` (controlled history), and `CT-C01` (minimal history control) in the source protocol. An agent lineage is a provenance record; **not by itself human identity, consciousness or proved individuation**.

The source names the following distinct metrics: `BPA` biographical predictive advantage, `CLS` cross-lineage specificity, `TCI` transplant continuity, `CAE` causal autobiography error, `RRA` retrolongitudinal reconstruction accuracy, and `ALI` authority-lineage integrity.

Controls include equal-token long context, retrieval, randomized/matched-other biography and a full CT subject. Interventions include memory ablation, policy rollback, subject/model transplant, self-narrative reset, fork, counterfactual replay and temporal reconstruction.

**LCI's distinct role:** investigate the *specificity and persistence of an artificial-agent developmental trajectory*. PEMS is a proposed analytical property; it is not a new result or an edit to the LCI preregistration.
